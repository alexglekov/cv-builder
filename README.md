# Integration for CV-Builder

## Бизнес анализ

### User Stories:

#### Поиск вакансии:
  - Как пользователь я хочу, чтобы система предлагала подходящие по информации из моего профиля ( проекты, персональная ) вакансии.
  - Как пользовать я хочу иметь список избранных вакансий.
  - Как пользователь я хочу видеть какие навыки мне надо подтянуть для избранных вакансий.
  - Как пользователь я хочу иметь помощника, который бы позволил 

#### Чат-Бот:
  - Хочу вводить информацию как голосом, так и текстом.
  - Хочу получать от него подходящие по моему профилю вакансии.
  - Хочу обновлять свои персональные данные.
  - Хочу сгенерировать резюме для вакансии, исключительно отвечая на вопросы от бота.
  - Хочу сгенерировать проект, который подходит для выбранной вакансии.
  - Хочу переводить свои проекты и персональную информацию на выбранный язык.
  - Хочу, чтобы бот исправлял ошибки в моем профиле.
  - Хочу помечать вакансии в избранные и отслеживать их.
  - Хочу получать рекомендации по выбранной вакансии.

### Страница избранных выкансий

На странице отображаются избранные пользователем вакансии, на которые он планирует подавать свое резюме и проходить собеседование. Вакансия может и не полностью подходить под его резюме, тогда в этом случае необходимо подсветить этот момент пользователю.<br>
Макет страницы избранных вакансий:
![Alt text](docs/vacancies_page.jpg)

#### Карточка вакансии из макета
  - В нераскрытой карточке находится краткая информация о вакансии.
  - В раскрытой карточке находится полная информация о вакансии, и, если информация, предоставленная пользователем, не подходит для вакансии - описание почему и в какаих моментах. ( стек технологий, языки, опыт работы )
  - Есть кнопка, которая перенаправляет на оригинальную страницу ваканси.
  - Есть кнопка, которая позволяет удалить вакансию из избранных.
  - Цвет зависит от того, на сколько информация предоставленная пользователем подходит к его избранной вакансии. ( стек технологий, опыт работы и т.д. ).
  
#### Требования
  - При любом изменении в профиле или проектах, информация по карточке должна актуализироваться
  - Актуализация должна происходить автоматически.

### Чат-Бот

#### Требования к реализации

- во время всего периода использования сервиса пользователь может начать взаимодействие с ботом путем нажатия на иконку с изображением бота в правом нижнем углу экрана;
- с ботом есть возможность общаться только на русском и английском языке;
- при каждом новом открытии диалогового окна сохраняется история переписки с ботом, при первом открытии бот приветствует пользователя и предлагает помощь, сообщая свои возможности пользователю;
- по умолчанию ввод сообщения для бота осуществляется текстом и отправляется путем нажатия на клавишу Enter или на специальную кнопку отправки сообщения;
- для начала диалога в голосовом формате пользователю необходимо нажать на кнопку с изображением микрофона, которая находится рядом с кнопкой отправки сообщения;
- во время ввода информации голосом ввод текстом не осуществляется;
- если пользователь ввел сообщение голосом, то и бот отвечает ему голосом;
- голосовая переписка дублируется в текстовом формате и сохраняется в истории сообщений в течение сеанса;
- перед внесением каких-либо изменений в базу данных бот обязательно уточняет введенную информацию и совершает действие только после утвердительного ответа пользователя;
- если бот не распознал запрос, тогда он просит изменить формулировку запроса;
- весь необходимый функционал бота описан в разделе User Stories.

#### Сценарии диалогов
    Тот или иной сценарий начинается по мере ввода ключевых слов. Соответственно, подраздел "Запуск" содержит в себе набор ключевых слов или фраз на русском языке, на которые отзывается бот и запускает сценарий. Затем описываются возможные варианты диалогов, где Б - это реплики бота, а К - вводная информация клиента. После окончания любого сценария бот задает вопрос по умолчанию. Во время общения с ботом на английском языке используются те же смысловые фразы, но переведнные на английский язык.

  **ВОПРОСЫ ПО УМОЛЧАНИЮ**
  - "Чем я могу помочь?"
  - "Пожалуйста, задайте Ваш вопрос"
  - "Чем Вам помочь?"

  **ПРИВЕТСТВИЕ**
  Запуск: привет, здравствуй, здравствуйте, добрый день/вечер, доброе утро, доброго времени суток, доброго утра/дня/вечера, доброй ночи, нужна помощь, помоги, вопрос 

  Б: "Здравствуйте! Чем могу помочь?"/"Привет! Чем могу быть полезна?"

  **ПОЛУЧЕНИЕ ВАКАНСИЙ**
  Запуск: покажи вакансии, дай информацию по вакансиям, хочу знать вакансии, какие вакансии мне подходят

  Б: "Загружаю вакансии согласно Вашему профилю"
  Б: *ссылки на 5 подходящих вакансий* + гиперссылка на страницу со всеми подходящими вакансиями "посмотреть еще..."

  **ОБНОВЛЕНИЕ ПРОФИЛЯ**
  Запуск: обнови/обновить профиль/данные, измени/изменить профиль/данные 

  Б: "Что именно Вы хотите поменять? Я могу помочь изменить следующие данные: ФИО, направление работы, образование, опыт работы, биографию"

  К:
  Если К ввел "фио", то Б: "Назовите новые данные об имени, фамилии и отчестве"
  Если К ввел "направление работы", то Б: "В каком направлении Вы планируете работать теперь?"
  Если К ввел "образование", то Б: "Какое образование мне считать корректным?"
  Если К ввел "опыт работы", то Б: "Какой у Вас опыт работы?"
  Если К ввел "биография", то Б: "Расскажите о себе вновь"

  К: *вводит информацию*
  Б: "Проверьте, правильно ли введены данные теперь?"
  Б: *печатает введенные данные*

  К:
  Если К ввел "да", то Б: "Вношу изменения..." + запускается скрипт обновления данных
  Если К ввел "нет", то Б: "Как жаль, видимо, произошел сбой. Давайте попробуем еще раз." + повторяет вопрос


  **ГЕНЕРАЦИЯ РЕЗЮМЕ**
  Запуск: сгенерируй/создай/сделай резюме

  Б: "Хорошо! Начинаем составление резюме..."
  Б: "Ваше ФИО - <выводит ФИО из профиля>?"

  К:
  Если К ввел "да", то Б: "Хорошо, продолжим"
  Если К ввел "нет", то Б: "Назовите Ваши корректные данные ФИО"

  Б: "Ваше образование <выводит образование из профиля>?"

  К:
  Если К ввел "да", то Б: "Тогда идем дальше"
  Если К ввел "нет", то Б: "Назовите Ваши корректные данные об образовании"

  Б: "Ваш опыт работы соответствует данной информации <выводит опыт работы из профиля>?"

  К:
  Если К ввел "да", то Б: "Продолжаем!"
  Если К ввел "нет", то Б: "Назовите Ваши корректные данные об опыте работы"

  Б: "На какую позицию Вы рассматриваете свою кандидатуру?"
  К: *вводит ответ*

  Б: "Перечислите свои навыки"
  К: *вводит ответ*

  Б: "Какие из следующих проектов Вы планируете указывать в резюме: <перечисляет все проекты>. Для качественного резюме выберите не более 3-х лучших проектов"
  К: *вводит ответ*

  Б: "Отлично, генерирую резюме!"
  *вывод ссылки на скачивание резюме*

  **ПЕРЕВОД РЕЗЮМЕ**
  Запуск: переведи, поменяй/смени язык, перевод 

  Б: "Поняла Ваш запрос! Какое из Ваших резюме мне необходимо перевести? <выводит список резюме>"
  К: *вводит ответ*

  Б: "Пару секунд, перевожу..."
  *вывод ссылки на скачивание переведенного резюме*

  **ИСПРАВЛЕНИЕ ОШИБОК**
  Запуск: исправь, проверь, ошибки

  Б: "Поняла Ваш запрос! Какое из Ваших резюме мне необходимо проверить на грамотность? <выводит список резюме>"
  К: *вводит ответ*

  Б: "Пару секунд, исправляю..."
  *вывод ссылки на скачивание исправленного резюме*

#### Список задач для каждого из серверов

На основном сервере необходимо сделать:
 - Необходимо будет добавить новую таблицу (модуль), которая соответствует таблице из бизнес анализа
 - Добавить методы CRUD для этой таблицы
 - Добавить новые методы для получения текущей всей информации о пользователе ( его проектах, опыте в годах и тд, ту информацию, что необходима для генерации резюме ).

На сервере для бота:
 - Необходимо будет добавить поддержку websocket соединения с клиентом
 - Необходимо будет добавить обработку базовых сообщений ( привествий, помощь )
 - Необходимо будет добавить поддержку диалога из User Stories

На сервере для интеграции:
 - Необходиом будет добавить ендпоинты для работы с интеграцией ( в интеграцию будут предоставлять информацию пользователя, а в ответ ожидаются вакансии с анализом, данные по таблице выше в бизнес анализе )

На стороне клиента:
 - Необходимо добавить чат с ботом
 - Необходимо добавить новую страницу с избранными вакансиями
